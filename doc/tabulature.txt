INTRODUCTION                                                     *tabulature*

Tabulature owns a hierarchy over real Neovim tabpages and exposes that state as
a Statuesque widget. It can persist snapshots and integrate with Continuity and
Manifold. Neovim 0.11 or newer is required.

==============================================================================
SETUP                                                   *tabulature-setup*

>lua
    require('tabulature').setup({
        style = 'inherit',
        manifold = false,
        persist_snapshots = true,
    })
<

Tabline rendering is owned by Statuesque. Include `{ name = 'tabulature' }` in
the configured tabline surface.

==============================================================================
COMMANDS                                             *tabulature-commands*

*:TabulatureNewTab*       Create a top-level tab with an optional label.
*:TabulatureNewSubtab*    Create a child of the current tab.
*:TabulatureNewNested*    Create a nested chain below the current tab.

==============================================================================
API                                                       *tabulature-api*

The root module exposes `setup()`, `create_tab()`, `create_subtab()`,
`create_nested()`, `current_tab_id()`, `adopt_current_tabpage()`, and
`publish()`.
